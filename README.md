# Kazi Sharmin — Portfolio

Personal portfolio site: full-stack development, deep learning research, and cybersecurity.

**Live:** 
portfolio-of-zahra.netlify.app

## Features
- Interactive terminal (try `help`, `whoami`, `projects`, `goto contact`)
- Animated network background on `<canvas>`, boot screen, glitch heading, scroll reveals
- Responsive (desktop and mobile), respects "reduce motion" settings
- Single static file, no build step, no dependencies

## Edit
All personal content is in the `ME` object at the top of the `<script>` in `index.html`.

## Deploy
Hosted on Netlify, auto-deployed from this repository on every push to `main`.
